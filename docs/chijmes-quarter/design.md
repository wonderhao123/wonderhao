# CHIJMES 参考分析与教堂街区重建

日期：2026-10-01。参考对象为新加坡 CHIJMES 建筑群；本项目是按岛内尺度重新设计，并非测绘复刻，也不将 CHIJMES 或其中商户标为个人作品。

## 参考依据

- [CHIJMES 官方历史导览](https://chijmes.com.sg/heritage/)：礼堂、Caldwell House、学校与修女院建筑的不同身份；彩色玻璃及花鸟柱头的装饰传统。
- [CHIJMES Hall 官方介绍](https://chijmes.com.sg/spaces/chijmes-hall/)：哥特式礼堂、高空间、彩色玻璃、柱与廊道细部。
- [官方目录及平面图](https://chijmes.com.sg/directory/)：已直接查看官方平面图。礼堂与 Caldwell House 独立，中央 The Lawn 与周边多个餐饮建筑相连，入口分布于街区边缘，另有地下层。图为商户导览，不提供可用于精确复刻的测绘尺寸。
- [URA 1997 建筑遗产奖记录](https://www.ura.gov.sg/-/media/Corporate/Get-Involved/Conserve-Built-Heritage/AHA/1997/AHA-1997----Chijmes.pdf)：旧建筑修复、新建筑尺度协调、适应性再利用。
- [URA 原 CHIJ 保育区](https://www.ura.gov.sg/conservation/find-a-building/conservation-portal/fchij/)：礼堂、Caldwell House、旧宿舍和孤儿院共同构成保育建筑群。

## 建筑与空间分析

| 层次 | 参考中可读出的设计关系 | 在 WONDERHAO 中的转译 |
| --- | --- | --- |
| 总平面 | 多栋历史建筑围绕开放庭院，不同院落与街道相接 | 将原单体教堂及硬铺广场改为完整街区；西侧礼堂、北东两翼回廊、南侧小会馆围合中央草坪 |
| 轮廓 | 礼堂尖塔突出，周边楼宇维持低层尺度 | 礼堂尖塔为唯一竖向主角，回廊两层，会馆更低；相邻城市高楼继续作为背景 |
| 礼堂 | 垂直比例、尖拱、分节立面和重复结构形成节奏 | 主堂、低侧廊、高侧窗、钟楼、八角尖顶与角部小尖塔；上升扶壁连接外侧墩柱与主堂 |
| 窗与细部 | 彩色玻璃、细柱及装饰使近景有层次 | 分色尖拱窗、窗套、中梃、钟楼百叶、檐口与柱脚；不声称复刻原作花鸟雕刻或宗教画面 |
| 回廊 | 连续有遮蔽的边界，让庭院既开放又有围合感 | 两层镂空尖拱、柱间通道、楼板与栏杆，房间退在廊后；开口不是贴在实体墙上的图案 |
| Caldwell House | 独立的古典建筑身份，与哥特式礼堂并置 | 单独的小会馆、较低瓦顶、古典窗框、柱式门廊与弧形花园凸厅 |
| 花园 | 草坪作为整组建筑的留白和方向参照 | 草坪保留开放中心，树木与花池布置在边缘，座椅面向庭院 |
| 当代使用 | 餐饮与活动让历史空间在日夜持续使用 | 加入桌椅、遮阳伞、树下休息区和连续庭院步道；不复制商户品牌或虚构业务链接 |
| 街道边界 | 多入口将内院与周围街道连接 | 南侧主门与东侧通道保持开放；保留图书馆、店屋与相邻庙宇的间距 |
| 夜景 | 建筑重点光与庭院活动照明共同建立尺度 | 白墙暖色洗墙、完整彩窗发光、廊下灯与矮柱灯；屋顶和草坪保留暗部，不增加动态点光 |

## 实施边界

- 地块约 128 × 135 米，沿用城市 20 米地面标高。具体数值来自本项目布局，非 CHIJMES 实际尺寸。
- 保留项目原有导航、作品映射、寺庙、图书馆、周围店屋、车辆与道路。教堂街区仍为城市景观，不捏造案例。
- 本次重建可浏览的外部建筑、回廊与公共空间；不新增礼堂室内游览，也不复刻原址地下商业层。
- 继续使用实例合批和现有程序材质；新增尖拱框、尖拱窗、八角尖顶、上升扶壁几何，无新增 npm 依赖、外部模型或贴图。
- 远景保留整组回廊与支撑，避免通用面积阈值剔除细柱后出现悬空拱券。标准和轻量模式共享布局。
- `lib/world/city-architecture.ts` 中的 `makeHeritageQuarter` 是可编辑来源，`scripts/build-city.mjs` 生成部署数据；`lib/world/vegetation.ts` 保留共享几何，`CityTerrain.tsx` 负责材质，`night-lighting.ts` 负责固定照明分布。
